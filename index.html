Privacy Policy for Color Picker - Eyedropper Tool

Effective date: October 12, 2026

Color Picker - Eyedropper Tool is a Chrome extension that lets users pick a color from the screen and copy it in color formats such as HEX, RGB, and HSL.

Information Collection

Color Picker - Eyedropper Tool does not collect, transmit, sell, or share personal information. The extension does not use analytics, tracking scripts, remote code, advertising, or third-party data brokers.

Local Storage

The extension uses Chrome local storage only to support its core functionality. It may store the following data on the user's device:

  • The most recently picked color
  • Pinned colors saved by the user
  • Recent color history saved by the user
  • Theme and automatic copy format preferences
  • Successful copy counts, quick-start completion, and review reminder milestones

This data stays on the user's device and is not sent to the developer or any external service.

Manual color values and contrast comparisons are processed locally. Importing a palette reads only the JSON file selected by the user; it does not upload that file. Exporting a palette downloads a JSON or CSS file to the user's device.

Permissions

Color Picker - Eyedropper Tool requests the storage permission only to save colors, color history, preferences, and usage milestones locally so the extension can remember them between sessions. It does not request access to website contents.

Third-Party Services

Color Picker - Eyedropper Tool does not use third-party analytics, advertising, or external servers to process user data.

Children's Privacy

Color Picker - Eyedropper Tool is not directed to children and does not knowingly collect personal information from children.

Changes to This Policy

This privacy policy may be updated if the extension's functionality changes. Any updated version will be published at the same policy URL.
