Privacy Policy for Native Color Picker

Effective date: June 22, 2026

Native Color Picker is a Chrome extension that lets users pick a color from the screen and copy it in color formats such as HEX, RGB, and HSL.

Information Collection

Native Color Picker does not collect, transmit, sell, or share personal information. The extension does not use analytics, tracking scripts, remote code, advertising, or third-party data brokers.

Local Storage

The extension uses Chrome local storage only to support its core functionality. It may store the following data on the user's device:

  • The most recently picked color
  • Pinned colors saved by the user
  • Recent color history saved by the user

This data stays on the user's device and is not sent to the developer or any external service.

Permissions

Native Color Picker requests the storage permission only to save colors and color history locally so the extension can remember them between sessions.

Third-Party Services

Native Color Picker does not use third-party analytics, advertising, or external servers to process user data.

Children's Privacy

Native Color Picker is not directed to children and does not knowingly collect personal information from children.

Changes to This Policy

This privacy policy may be updated if the extension's functionality changes. Any updated version will be published at the same policy URL.
